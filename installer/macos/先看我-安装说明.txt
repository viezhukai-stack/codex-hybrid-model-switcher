Codex Hybrid macOS 安装说明
===========================

一、如果你拿到的是轻量云端包
- 先安装并登录原版 Codex Desktop。
- 解压整个 zip。
- 双击 Install Codex Hybrid.command。
- 按提示填写云端 base_url、model 和 API key。

二、如果你拿到的是完整本地模型包
- 先安装并登录原版 Codex Desktop。
- 解压整个 zip，确保 payload/models/local-gemma 还在包内。
- 双击 Install Codex Hybrid.command。
- 不需要云端 API key，也不需要手选 GGUF/mmproj。
- 安装器会复制约 6GB 本地模型，请耐心等待。
- local smoke 通过后，会先执行安全 dry-run。
- 只有你完全退出 Codex Desktop，并输入 APPLY 后，才会真实切换。
- 如果想保留旧项目对话可见性，按提示输入 MIGRATE。安装器会先 dry-run，真实迁移前会备份历史数据库。

三、安全边界
- 不包含原版 Codex Desktop，需要从官方页面安装。
- 不安装 CC Switch。
- 正常切换不修改 auth.json、models_cache.json、state_5.sqlite、sessions 或 rollout logs。
- 只有你明确输入 MIGRATE 时，才会备份并迁移历史 provider 桶。
- 右下角模型名不作为真实切换依据，以外部 provider/config 为准。

四、如果提示缺少 Python
- 需要安装 Python 3.10 或更高版本。
- 安装器会打开官方 macOS Python 下载页。
- 安装完成后，重新双击 Install Codex Hybrid.command。
